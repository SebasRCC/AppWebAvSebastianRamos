# 2026-10-21 · PoliMusic (ASP + SQL Server 2025)

## Construido
Clon de Spotify "PoliMusic · Ágora Sonora" en Classic ASP (VBScript) sobre la base
`BDD_PoliMusic` del script del curso. No se crearon tablas ni columnas nuevas.

Archivos principales: `login.asp`, `logout.asp`, `default.asp`, `songs.asp`, `artists.asp`,
`albums.asp`, `playlists.asp`, `playlist.asp`, `api_play.asp`, `includes/{init,config,db,auth,icons,head,foot}.asp`,
`css/app.css`, `js/app.js`, `assets/`, `README.md`, `run-iisexpress.ps1`.

## Decisiones técnicas
- Conexión ADODB con cadena de proveedores en cascada (MSOLEDBSQL → SQLOLEDB → SQLNCLI11).
- Login valida contraseña en texto plano **o** SHA1 vía `HASHBYTES` en SQL (el script mezcla ambos).
- Todas las consultas parametrizadas (`CreateParameter`); salida escapada con `H()`.
- Rutas del script (`~/songFiles/...`) resueltas por `AssetUrl()` a `assets/...` con fallback a imagen por defecto.
- Roles: `USER_TYPE 1` = admin (CRUD canciones/artistas/álbumes + todas las playlists),
  `USER_TYPE 0` = solo CRUD de playlists propias (validado en servidor, no solo en UI).
- JS: reproductor persistente, cola desde el Song List, PLAYS incrementado por `fetch` a `api_play.asp`,
  duración real de cada MP3 leída con `preload=metadata`.

## Problemas encontrados y solución (importante)
1. **IIS Express con `/path:` no sirve el sitio** (404 en todo): usa `empty_wwwroot`.
   Solución: copiar `AppServer\applicationHost.config`, reemplazar `%IIS_BIN%\AppServer\empty_wwwroot`
   por la ruta del proyecto y arrancar con `/config:` + `/site:"Development Web Site"`.
   Está automatizado en `run-iisexpress.ps1` (puerto 8099).
2. **`<asp>` dentro de `web.config` rompe Classic ASP** en IIS Express:
   `New Application Failed: Could not Init the AppConfig, hr = 0x80070021` → HTTP 501.
   No declarar la sección `<asp>` a nivel de sitio.
3. **`%>` dentro de un comentario VBScript cierra el bloque de script** y el archivo se imprime como texto.
4. **VBScript es case-insensitive**: `Dim txt` dentro de una función oculta la función global `Txt()`
   → error "No coinciden los tipos". Evitar nombres locales iguales a funciones globales
   (`Txt`, `Num`, `H`, `Ico`, `IIf`).
5. Los includes anidados son relativos al archivo que los contiene; `includes/init.asp` centraliza
   `config + db + auth + icons` y `head.asp` NO debe volver a incluirlos (funciones duplicadas).
